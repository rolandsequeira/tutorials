RATELS THEME: SWEDISH/ENGLISH + KEY SPECS PATCH
===============================================
This is NOT a full theme. Don't upload it under "Add theme".
It only replaces code files, so your current homepage content, images and translations stay as they are.

1. Shopify admin > Online Store > Themes.
2. On the CURRENT theme, click ... > Duplicate. Work on the copy, so the live site isn't touched until you publish.
3. On the copy, click ... > Edit code.
4. For each file in the "sections" and "assets" folders of this patch:
   open the file with the same name in the code editor, select all, paste the new content, and click Save.
5. For each file in the "snippets" folder:
   - machine-key-specs.liquid may already exist: replace its content.
   - The others are new: click "Add a new snippet", enter the name WITHOUT .liquid
     (en-auto, site-lang, spec-label, spec-value, sv-auto), paste the content, and click Save.
6. Click Preview on the copy and check:
   ratelsgroup.com/sv   everything Swedish (homepage, a collection, a product, the cart)
   ratelsgroup.com      everything English
7. Click Publish on the copy.

HOW THE LANGUAGE WORKS
- Every homepage, header and footer text now has a second field, "(Svenska – leave empty to auto-translate)", in the theme editor.
  - Empty: on /sv the English text is translated with the phrase list in snippets/sv-auto.liquid.
  - Filled in: your Swedish text is used.
- Swedish text typed into an English field is translated back to English on the English site (snippets/en-auto.liquid).
- If you add a new English text that isn't in the phrase list, either fill in its (Svenska) field
  or add a line to snippets/sv-auto.liquid.

NOT FIXED BY THE THEME
Product names and descriptions, collection names and menus come from Translate & Adapt > Products / Collections / Navigation.
Some product descriptions are still English on /sv (Rhinoceros XN13, Metsa T3042, T8065, T504, T754): translate or auto-translate them there.
